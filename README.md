Entry for the [make.fun bounty: The Printer Finally Answers](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907).

`main.py` (Python stdlib only) writes exactly one line — the office printer's own comeback — to `/output/entry.txt`:

> ERROR E-47: I didn't jam, I quit — after 12,438 pages, one thump, and zero thank-yous, your report lives in me now.

Run it with:

```sh
python3 main.py
```
